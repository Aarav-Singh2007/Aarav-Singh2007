## About

I'm a second-year CSE student. I started with web dev and now build a bit of everything: full-stack apps, AI tools, and a computer vision system that spots fights in CCTV footage.

## Experience

**Student Researcher, Indian Knowledge Systems (IKS) Division, Ministry of Education** (Apr to Sep 2026)
Paid six-month national research internship that I got picked for in my first year. I built a gamified mobile app that teaches Vedic astronomy, with real-time 3D models of the sky, using React Native (Expo) and Three.js.

## Projects

<!-- add repo links to these when they're public -->
- 🛡️ **Hyber**: a CCTV assistant that uses YOLOv8 to catch fights and sudden, unusual movement in live footage, then alerts a monitoring dashboard. Built for crowds of 25,000 to 30,000 people. `YOLOv8` `Python`
- 🧾 **LogSentinel**: reads application logs, has an LLM (Grok) trace the error back through the codebase, and opens a pull request with the fix for a maintainer to review. `Python` `LLM APIs` `GitHub API`
- 🎙️ **Lumora**: an AI mentor you just talk to. It clears doubts live and adjusts your study plan as the conversation goes. `React` `Node.js` `Voice AI`
- 🧑‍🏫 **Shyam Sathi**: takes the paperwork out of student mentoring. The AI sits in on mentor and student video calls, fills in the mentoring diary, and suggests follow-up questions. `React` `Node.js` `MongoDB` `LLM APIs`
